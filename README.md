# Sanjeevani Pharmacy — Free Website

## Publish for free with GitHub Pages

1. Create a free account at GitHub.
2. Create a new **public repository** named `sanjeevani-pharmacy`.
3. Upload `index.html`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. GitHub will provide a free `github.io` website address.

## Before publishing
- Verify the WhatsApp number in `index.html`.
- Replace the Google Maps placeholder with the pharmacy's exact Google Maps URL.
- Update delivery, discount, BP/sugar testing and opening-hours claims to match your current offers.
- Add your logo if desired.
